# CineFlow 电影推荐规则

## 适用范围

本文描述热门推荐和登录用户个性化推荐的确定性业务规则，不保证某次查询一定返回哪些电影，因为电影状态、评分、评论和热度会变化。

## 通用规则

- 推荐数量 `limit` 必须在 1 到 50 之间。
- 推荐结果只能包含状态为 `AVAILABLE` 的电影，下架电影不得进入结果。
- 同一次推荐结果不得包含重复电影。
- 电影的实时评分、热度和可用状态必须以数据库或电影 API 为准。

## 热门推荐

- 未指定用户偏好时使用热门推荐。
- 热门电影按照热度降序、评分降序、电影 ID 升序排列。
- 热门推荐只返回 `AVAILABLE` 电影。

## 个性化推荐

- 个性化推荐需要登录用户身份。
- 系统从用户评分不低于 7 分的评论中提取偏好类型，按评分较高的评论优先处理，最多使用 20 条高分评论并保留最多 3 个不重复类型。
- 个性化候选电影必须匹配至少一个偏好类型、状态为 `AVAILABLE`，并排除该用户已经评论过的电影。
- 个性化候选电影按照评分降序、热度降序、电影 ID 升序排列。
- 个性化候选数量不足时，使用热门电影补足，并排除已经选中的电影。
- 如果用户没有可用的类型偏好，结果全部由热门电影补足。

## 解释边界

- 规则可以解释“推荐为什么偏向某些类型”，但不能仅凭静态文档回答“我现在会被推荐哪几部电影”。
- 查询用户当前推荐结果属于实时数据问题，应调用 `/api/recommendations/me`。
- 查询公共热门推荐应调用 `/api/recommendations/hot`。

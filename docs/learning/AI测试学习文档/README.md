# CineFlow AI 测试学习路线

这套文档面向“会一点 Python，但没有系统学习过大模型应用”的读者。你不需要先学习模型训练、微积分、Transformer 数学推导，也不需要购买显卡。

我们的目标不是让你背 AI 名词，而是让你最终能够完成下面这件事：

```text
给 CineFlow 接入一个电影 AI 助手
          ↓
准备可以重复运行的测试数据
          ↓
检查模型有没有胡说、越权、泄密或调用错工具
          ↓
比较不同 Prompt 和模型的质量、速度与费用
          ↓
形成自动化报告和发布门禁
```

## 如何使用这些文档

1. 每周按“第 1 天 → 第 7 天”的顺序学习。
2. 文档中的代码不要只看，必须自己敲一遍并运行。
3. 每完成一天，都执行当天的“验收清单”。
4. 看不懂一个术语时，先看它旁边的生活例子，不要急着背定义。
5. 真实 API 会产生费用。没有 API Key 时，先完成不需要联网的练习。
6. AI 输出只能作为建议；业务是否正确，优先由数据库、OpenAPI、Pydantic 和 pytest 判断。

## 学习纪律

永远遵守下面四条：

- 不把真实 API Key 写进 Python、Markdown、YAML 或 Git。
- 不让模型生成内容后自动执行支付、退款、删库或生产环境操作。
- 不因为“模型说得像真的”就相信它，必须找可验证的证据。
- 不只测试一次。模型输出有随机性，重要用例要重复执行并统计成功率。

## 你会频繁使用的目录

```text
MovieTicketingAndRecommendationSystem/
├─ CineFlowAPI/                 # 被测后端
├─ CineFlowAutoTest/            # pytest 自动化测试工程
│  ├─ llm/                      # 现有大模型辅助代码
│  ├─ cases/                    # YAML 数据驱动用例
│  ├─ schemas/                  # 响应 JSON Schema
│  └─ tests/                    # pytest 测试
├─ cineflow-openapi.json        # API 契约
└─ AI测试学习文档/              # 当前学习文档
```

## 完成一周的判定方式

不是“看完文档”就算完成，而是同时满足：

- 能用自己的话解释核心概念。
- 能独立运行示例。
- 能故意制造一个错误并解释错误原因。
- 能完成周末小项目。
- 能回答文档最后的自测题。

# CineFlow 文档导航

项目文档统一收纳在本目录，根目录仅保留源码工程、CI/CD 配置和项目级配置。

## 目录结构

- `technical/`：系统设计、自动化测试、数据库、JMeter、Postman 与质量门禁说明。
- `learning/`：阶段性学习资料，目前包含 8 周 AI 测试学习路径。
- `interview/`：测试岗位面试题、项目讲解与深挖题库。
- `api/`：OpenAPI 接口规范。
